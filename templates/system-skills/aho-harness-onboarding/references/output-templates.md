# Output Templates

Use these headings when producing onboarding output.

## ProjectContextPack

```markdown
## ProjectContextPack

- Project:
- Source root:
- Memory mode:
- Evidence read:
- Project state:
- ECL readiness:
- Product / domain:
- Primary entrypoints:
- Important directories:
- Verification commands:
- Source-safety boundaries:
- Unknowns:
- Main-Agent delegation hints:
```

## Harness Onboarding Proposal

```markdown
## Harness Onboarding Proposal

- Goal:
- Deterministic preparation already handled by AHO:
- Proposed project-specific docs or scripts:
- Files to create or update:
- Evidence:
- Risks:
- Human gates:
- Verification:
- Non-goals:
```

## Onboarding Decision Summary

```markdown
## Onboarding Decision Summary

- Ready for ordinary AHO planning:
- Needs user confirmation:
- Needs read-only follow-up:
- Must not do:
- Next real AHO gate:
```

## Compact Mode

If the project is already Harness ready, keep the output short:

```markdown
## ProjectContextPack
- State: Harness Ready
- Evidence read:
- Fresh context:
- Delegation hint:

## Onboarding Decision Summary
- Ready for ordinary AHO planning: yes
- Next real AHO gate:
```
