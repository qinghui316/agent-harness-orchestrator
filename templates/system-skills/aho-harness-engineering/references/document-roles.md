# Document Roles

- `AGENTS.md`: compact routing map and current pointers, never an archive ledger.
- `docs/STATUS.md`: short current handoff, never full chronology.
- `docs/ECL.md`: durable lifecycle constraints.
- `docs/BOUNDARIES.md`: reusable ownership, authority, projection, and recovery boundaries.
- Stable project memory: durable project facts and constraints, not transient run history.
- Change/archive artifacts: accepted plan, evidence, review, closeout, and historical detail.
- Generated index/ledger: mechanical history and discovery.

Do not duplicate one fact across roles unless each copy changes a distinct current decision.
