# Documentation Entropy

Current documentation should help the next Agent decide and act. Archives own
chronology and detailed evidence.

Check for stale current-state claims, duplicate rules, historical logs copied
into handoff documents, entry guidance becoming a manual, rules better enforced
by mechanical checks, and links to superseded owners.

Do not optimize for line count alone. Retain project-specific detail when it is
current and decision-relevant. Compress or retire content when its ongoing
context cost exceeds its value.
