# ECL Delta Analysis

Build the semantic bundle from evidence before requesting publication:

1. State each project fact and its source evidence.
2. Classify it as current, accepted target, decision, guide, unknown, or historical only.
3. Assign one durable project-Skill Owner and layer. Merge with an existing Owner when possible.
4. Describe the complete create, replace, retire, or takeover delta. Do not hide retirement inside a
   replacement or retain both old and new Owners.
5. Keep generated catalog/index artifacts renderer-owned and keep operational sidecar state out of
   project knowledge.

The required four files are one candidate contract, not independent suggestions. Their project id,
module names, source paths, ownership, architecture, audit findings, and creation delta must agree.
Artifact files referenced by the delta must exist in the bundle and contain no machine path, secret,
temporary transaction data, or unsupported current claim.
