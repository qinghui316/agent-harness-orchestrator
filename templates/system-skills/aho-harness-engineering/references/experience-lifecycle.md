# Experience Lifecycle

- Promote: repeated, current, project-relevant evidence justifies durable guidance or a mechanical check.
- Retain: the current expression remains accurate, concise, and correctly owned.
- Merge: several current expressions should become one authoritative statement.
- Retire: newer evidence makes the current expression obsolete or misleading.
- Archive-only: useful history does not belong in current operating context.

Promote behavior, ownership, and enforceable constraints rather than incident
names or one-off fixes. A no-op still requires this scan during Evolution.
